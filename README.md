# wpr-education

Wisconsin education data tracker for Wausau Pilot & Review — ACT results,
graduation, dropouts, chronic absenteeism, and enrollment for Marathon County
school districts, with statewide comparison. Built on Wisconsin DPI WISEdash
statewide download files.

Pipeline ingests all of Wisconsin; `config/districts.json` decides what gets
presented. See `CLAUDE.md` for architecture, invariants, and current tasks.
